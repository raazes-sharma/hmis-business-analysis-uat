
# HMIS Business Analysis & UAT Portfolio

## About This Project

This is an independent learning and professional portfolio project based on a fictional Hospital Management Information System (HMIS).

It demonstrates practical knowledge of Business Analysis, Software Testing, User Acceptance Testing (UAT), requirements documentation, workflow analysis, issue tracking & Resolution.

## Project Objectives

- Understand business requirements.
- Document functional requirements.
- Map hospital operational workflows.
- Prepare software test scenarios and test cases.
- Conduct sample UAT activities.
- Document software defects and issues.
- Validate expected system behavior.

## Project Scope

### 1. Business Analysis
- Requirement gathering
- Functional requirements
- Business process documentation
- Workflow mapping

### 2. Software Testing
- Test scenario preparation
- Test case documentation
- Functional testing
- Positive and negative testing

### 3. User Acceptance Testing
- UAT planning
- Test execution
- Expected vs actual results
- UAT sign-off documentation

### 4. Defect Management
- Bug identification
- Defect reporting
- Severity and priority classification
- Retesting and closure

## HMIS Modules Covered

1. Patient Registration
2. Patient Billing
3. Appointment Management
4. Laboratory Information System
5. Pharmacy
6. Inventory
7. Admission and Discharge

## Project Deliverables

Documentation and sample exercises will be added progressively:

- Business Requirements Document (BRD)
- Functional Requirements Document (FRD)
- Process Flow Diagrams
- Software Test Cases
- UAT Test Reports
- Bug and Defect Reports
